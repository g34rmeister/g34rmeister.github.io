2.4 Intro to ROS (Vendor-Agnostic)

Gerald Lê Draft

01. One layer for every robot

Every robot maker has its own language and tools, so skills and code do not carry over from one brand to another. Middleware such as ROS (Robot Operating System) adds a common layer on top. Developers write C++ or Python against ROS, and drivers translate to each robot’s native interface.

ROS is used especially widely in mobile robotics, and simulators let developers build a digital twin of a robot to test code before touching real hardware.

02. Where to go next

The Robot Operating System chapter covers ROS in depth: what it is, how ROS 2 differs from ROS 1, how to install it, a first example, and its most useful tools.
