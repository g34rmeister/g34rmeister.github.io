3.3 Installing ROS on Your Local Environment

Gerald Lê Draft

01. Windows (x86-64)

The current long-term support release, ROS 2 Lyrical Luth, supports Windows 11 on 64-bit x86 only. It is installed from a binary archive, with the pixi package manager providing the dependencies, as described in the official guide. If you are on Windows 10, the previous LTS release, Jazzy Jalisco, still supports it.

A popular alternative is WSL 2 (Windows Subsystem for Linux): install Ubuntu inside Windows and then follow the Linux instructions below. Many tutorials assume Linux, so this route usually causes fewer surprises.

02. Windows (ARM)

ROS 2 has no official support for Windows on ARM. The practical route is to run Ubuntu for ARM inside WSL 2 or a virtual machine and install ROS 2’s Linux packages there, since 64-bit ARM (arm64) Ubuntu is a fully supported (Tier 1) ROS 2 platform.

03. macOS (ARM)

macOS is only a Tier 3 platform for ROS 2: there are no official binary packages, and installing natively means building ROS 2 from source. The more reliable options on an Apple Silicon Mac are running ARM Ubuntu in a virtual machine (for example UTM or Parallels) or using a Docker container with ROS 2 installed.

04. Linux (x86)

Linux is ROS’s home platform, and each ROS 2 release targets a specific Ubuntu version. The current long-term support release, ROS 2 Lyrical Luth, was released on May 22, 2026, targets Ubuntu 26.04 and is supported until May 2031. The previous LTS, Jazzy Jalisco, targets Ubuntu 24.04 and is supported until May 2029.

First set up the ROS 2 package repository, which is now done by installing the ros2-apt-source package as shown in the official guide. Then install and set up ROS with: 

sudo apt update
sudo apt install ros-lyrical-desktop
source /opt/ros/lyrical/setup.bash

On Ubuntu 24.04 with Jazzy, replace lyrical with jazzy. The source line has to run in every new terminal (or be added to ~/.bashrc) so the ros2 command can be found.
