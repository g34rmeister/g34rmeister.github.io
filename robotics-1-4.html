1.4 Preliminary Requirements

Gerald Lê

01. Python

Python is widely used in robotics for scripting, testing and higher-level logic, and it is one of the two main languages used with ROS. The Universal Robots language URScript also has Python-like syntax.

  • The Python Tutorial (python.org)

02. C++

C++ is the other main ROS language, and Arduino sketches are written in a simplified form of it. It is the usual choice when code has to run fast and close to the hardware.

  • LearnCpp.com

03. Some math (calculus, linear algebra)

Calculus shows up in control, for example the integral and derivative terms of a PID controller. Linear algebra is how robots describe positions, orientations and the motion of their joints.

  • MIT OpenCourseWare 18.01: Single Variable Calculus
  • MIT OpenCourseWare 18.06: Linear Algebra

04. Learning mentality

When robot code is wrong, the robot tells you right away: it drives into a wall, stalls, or grips too hard. That feedback is immediate and impersonal. The most useful mindset is to treat each failure as information, test, adjust and try again, rather than expecting to get it right the first time.

05. Assembly language

Assembly language is a low-level language in which each instruction corresponds closely to one machine instruction of a specific processor. You rarely write whole robot programs in assembly, but knowing what it looks like helps you understand what a microcontroller is actually doing: registers, memory, timing and interrupts.

That understanding pays off when code has to be fast and predictable, such as reading an encoder inside an interrupt or generating precise PWM timing.

  • Nand2Tetris: build a computer from logic gates up to assembly and beyond

06. Networking basics

Robots rarely work alone. Industrial robots talk to PLCs, cameras and other machines over Ethernet, and ROS 2 nodes exchange messages over the network. Useful basics:

  • IP addresses and subnets: how devices on a network find each other; a robot controller and a PC usually need addresses on the same subnet to communicate.
  • TCP vs. UDP: TCP guarantees delivery and order; UDP is lighter and faster but can drop packets. ROS 2’s default middleware, DDS, runs over UDP.
  • Ports: a single device runs many services, each listening on its own port number. Modbus TCP, for example, uses port 502.
  • Industrial protocols: factory equipment often uses protocols such as Modbus TCP, EtherNet/IP or PROFINET on top of Ethernet.
  • Computer Networks: A Systems Approach (free online book)
Try it
  1. Write a short Python or C++ program that converts a distance in centimeters to inches. If you can do this comfortably, you have enough programming to start.
  2. Look up your computer’s IP address and subnet mask, and work out which other addresses would be on the same subnet.
