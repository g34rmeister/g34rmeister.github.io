Robotics Open-Source Map

Gerald Lê

01. Overview

This page is a map of the open-source projects used across robOSStics. It summarizes what each project does, its license, where its source code is hosted, and how to make a first contribution. To learn the full contribution workflow, including licensing basics, issue labels, and pull requests, see Chapter 3: How to Contribute to Open Source.

02. ROS 2

What it is The Robot Operating System (ROS) is a set of software libraries and tools that help you build robot applications.[1]
License Every ROS 2 package must have a LICENSE file, typically under the Apache 2.0 license unless an existing permissive license is in place.[2]
Where the code lives ROS 2 source code lives across repositories in the ros2 and ament organizations on GitHub.[3]
How to start contributing First-time contributors to ROS 2 are encouraged to begin by looking at issues labeled good first issue across the repositories.[3]
How it is run Becoming a maintainer of ROS 2 repositories is an invitation-only process evaluated approximately every three months based on contributions and reviews.[3]

Used in these lessons: 4.1 Definition and Introduction and 4.6 Writing Your First ROS 2 Package.

03. MoveIt 2

What it is MoveIt 2 is an open source robotics manipulation platform for developing commercial applications, prototyping designs, and benchmarking algorithms.[4]
License MoveIt 2 is released under the BSD 3-Clause License.[5]
Where the code lives MoveIt 2’s source code is on GitHub in the moveit/moveit2 repository.[4]
How to start contributing Newcomers to MoveIt can start contributing by finding GitHub issues labeled Good First Issue.[6]
How it is run PickNik Inc is leading the development of the MoveIt open source project.[4]

Used in these lessons: 4.8 Moving an Arm with MoveIt 2.

04. Nav2

What it is Nav2 is the ROS 2 navigation framework; its README links its navigation plugins, general tutorials and algorithm developer tutorials.[7]
License Nav2 is available under Apache-2.0, BSD-3-Clause, or both, depending on the package; each package’s package.xml gives its license, and changes to an existing file use that file’s license.[8]
Where the code lives Nav2’s source code is on GitHub in the ros-navigation/navigation2 repository.[7]
How to start contributing Nav2 directs prospective contributors to its development guides involvement documentation page for how to contribute.[7]
How it is run Open Navigation LLC provides project leadership, maintenance, development, and support services to the Nav2 and ROS community.[7]

Used in these lessons: 3.3 How Robotics Projects Work.

05. ros2_control

What it is The ros2_control package is a part of the ros2_control robot control framework.[9]
License Any contribution made to ros2_control is submitted under the Apache 2 License as dictated by that license.[10]
Where the code lives The ros2_control codebase is organized across repositories including ros2_control, ros2_controllers, and ros2_control_demos.[10]
How to start contributing Newcomers can find issues suitable for a first contribution using the dedicated Contributing Board project board.[10]
How it is run Every pull request must be explicitly approved by two maintainers before it can be considered for merging.[10]

Used in these lessons: 4.8 Moving an Arm with MoveIt 2 and 10.2 Capstone: ROS 2 Pick-and-Place with MoveIt 2.

06. Gazebo

What it is Gazebo includes gz-sim, a high-fidelity 3D rigid-body dynamic simulator.[11]
License Gazebo Sim is released under the Apache License 2.0.[12]
Where the code lives Gazebo and its component libraries are hosted in the Gazebo Organization on GitHub.[11]
How to start contributing Maintainers triage issues and apply the help wanted label to issues that the team thinks should be tackled by the community.[11]
How it is run Gazebo pull requests can be merged once they have at least one approval from the core team, zero unresolved comments, passing CI, and passing DCO.[11]

Used in these lessons: 10.2 Capstone: ROS 2 Pick-and-Place with MoveIt 2.

07. OpenCV

What it is OpenCV is an open source computer vision library.[13]
License Contributors must agree to contribute their code under the OpenCV Apache 2.0 license.[14]
Where the code lives OpenCV code is hosted on GitHub at https://github.com/opencv/opencv with all new algorithms directed to the opencv_contrib repository.[14]
How to start contributing Contributors should read the contribution guidelines wiki before starting work on a pull request.[13]
How it is run When a reviewer and BuildBot approve a pull request, an approval comment is added signaling OpenCV maintainers that they can merge the pull request.[14]

Used in these lessons: 7.3 Image Processing Basics and 7.6 Lab: A ROS 2 Camera Pipeline.

08. PCL

What it is The Point Cloud Library (PCL) is a standalone, large scale, open project for 2D/3D image and point cloud processing.[15]
License PCL is released under the terms of the BSD license and is free for commercial and research use.[15]
Where the code lives PCL source code and releases are hosted on GitHub in the PointCloudLibrary/pcl repository.[15]
How to start contributing Anyone wishing to contribute to PCL is asked to read the CONTRIBUTING.md guide in the repository master branch.[15]
How it is run PCL is financially supported by a consortium of commercial companies through its non-profit organization, Open Perception.[15]

Used in these lessons: 7.4 3D Sensing.

09. Universal Robots Client Library

What it is The Universal Robots Client Library is a C++ library for accessing Universal Robots interfaces to implement drivers for robotic manipulators.[16]
License The majority of the Universal Robots Client Library is licensed under the Apache-2.0 license.[16]
Where the code lives The source code is on GitHub in the UniversalRobots/Universal_Robots_Client_Library repository.[16]
How to start contributing The repository supports pre-commit for automatic code formatting, so install it before your first commit.[16]
How it is run The library was developed in collaboration between Universal Robots A/S and FZI Research Center for Information Technology.[16]

Used in these lessons: 9.6 Lab: Check a Robot's State from Python.

10. Universal Robots ROS 2 driver

What it is The Universal Robots ROS 2 driver is a manipulator driver supporting cobot features like safeguard stop and emergency stop pause.[17]
License The UR ROS 2 driver is released under the BSD 3-Clause License.[18]
Where the code lives The source code is on GitHub in the UniversalRobots/Universal_Robots_ROS2_Driver repository, which keeps branches for specific ROS 2 distributions such as kilted.[17]
How to start contributing Contributor guidelines instruct developers to install pre-commit and clang-format 14 so code is auto-formatted whenever a commit is made.[17]
How it is run The driver is built on top of the Universal Robots Client Library.[17]

Used in these lessons: 4.9 ROS-Industrial and Vendor Drivers.

11. Wireshark

What it is Wireshark is an open-source network analyzer tool.[19]
License Wireshark is released under the GNU General Public License, version 2.[20]
Where the code lives Wireshark's code repository and review system is hosted on GitLab at https://gitlab.com/wireshark/wireshark.[19]
How to start contributing Contributors wishing to submit code changes to Wireshark create a merge request on GitLab following instructions in the Developer's Guide for patches.[19]
How it is run The development of Wireshark is supported by the non-profit Wireshark Foundation.[19]

Used in these lessons: 8.6 Network Design, Security and Diagnostics.

12. Contributing to robOSStics

To contribute directly to the robOSStics course platform itself, see CONTRIBUTING.md for instructions on fixing typos, suggesting new sources, and submitting pull requests.
