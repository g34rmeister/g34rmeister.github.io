Chapter 6: Capstone Projects

Gerald Lê

01. Overview

The first five chapters each teach one part of industrial robotics. This chapter asks you to put those parts together. Each capstone is a small project with milestones, a list of what to hand in, and a grading rubric, so it can be used as a course project or worked through on your own.

You do not need to do all three. Pick the project that matches the tools you have: a free robot simulator for 6.1, a computer that runs ROS 2 for 6.2, or an Arduino kit and a small DC motor with an encoder for 6.3. Each project page lists the lessons it builds on, so you can go back and review them before you start.

02. The projects

  • 6.1 Simulated work cell: lay out a cell in a vendor simulator, program a pick-and-place cycle with I/O and error handling, and check it against the safety ideas from Chapter 4. Builds on Chapters 1, 2 and 4.
  • 6.2 ROS 2 pick-and-place: plan and run a pick-and-place task for a simulated arm with MoveIt 2. Builds on Chapter 3.
  • 6.3 Speed-controlled wheel: build a motor, encoder and H-bridge rig, and hold a target speed with a PID loop inside a state machine. Builds on Chapter 5.

03. Articles in this chapter

  1. 6.1 Capstone: Build a Simulated Work Cell: Capstone project: build a simulated pick-and-place work cell in URSim or ABB RobotStudio with gripper I/O, a safety configuration and a FAT-style test sheet, graded by milestones and a four-level rubric.
  2. 6.2 Capstone: ROS 2 Pick-and-Place with MoveIt 2: Capstone project: build a pick-and-place task for a simulated UR5e with ROS 2, MoveIt 2 and the MoveIt Task Constructor on mock hardware or Gazebo, with milestones, tests and a rubric.
  3. 6.3 Capstone: Speed-Controlled Wheel: Capstone project: build an Arduino speed-controlled wheel with a quadrature encoder, H-bridge driver, PID loop and a state machine with ramps and a FAULT state, with milestones, safety and a rubric.

04. Chapter quiz

Before you start a project, take the Chapter 6 quiz to check that you know what each project asks for. Each question links back to the project page that covers it.

05. Feedback

robOSStics is being tested with students. If you finish a capstone, or get stuck on one, please get in touch and mention which project and milestone.
