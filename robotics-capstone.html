Chapter 10: Capstone Projects

Gerald Lê

01. Overview

The chapters before this one each teach one part of robotics. This last chapter asks you to put them together. Each capstone is a small project with milestones, a list of what to hand in, and a grading rubric, so it can be used as a course project or worked through on your own.

You do not need to do them all. Projects 10.1 to 10.3 each go deep in one area; pick the one that matches the tools you have: a free robot simulator for 10.1, a computer that runs ROS 2 for 10.2, or an Arduino kit and a small DC motor with an encoder for 10.3. Project 10.4 uses a little of everything, needs only a computer, and ends with a real open-source pull request. Each project page lists the lessons it builds on, so you can go back and review them before you start.

02. The projects

  • 10.1 Simulated work cell: lay out a cell in a vendor simulator, program a pick-and-place cycle with I/O and error handling, and check it against the safety ideas from Chapter 5. Builds on Chapters 1, 2 and 5.
  • 10.2 ROS 2 pick-and-place: plan and run a pick-and-place task for a simulated arm with MoveIt 2. Builds on Chapter 4.
  • 10.3 Speed-controlled wheel: build a motor, encoder and H-bridge rig, and hold a target speed with a PID loop inside a state machine. Builds on Chapter 6.
  • 10.4 Open-source cell monitor: build a ROS 2 program that reads robot state, cell handshake signals and a camera check from stand-in servers, keeps a maintenance log, and is published with a README, license and a real pull request. Builds on Chapters 3, 4, 7, 8 and 9.

03. Articles in this chapter

  1. 10.1 Capstone: Build a Simulated Work Cell: Capstone project: build a simulated pick-and-place work cell in URSim or ABB RobotStudio with gripper I/O, a safety configuration and a FAT-style test sheet, graded by milestones and a four-level rubric.
  2. 10.2 Capstone: ROS 2 Pick-and-Place with MoveIt 2: Capstone project: build a pick-and-place task for a simulated UR5e with ROS 2, MoveIt 2 and the MoveIt Task Constructor on mock hardware or Gazebo, with milestones, tests and a rubric.
  3. 10.3 Capstone: Speed-Controlled Wheel: Capstone project: build an Arduino speed-controlled wheel with a quadrature encoder, H-bridge driver, PID loop and a state machine with ramps and a FAULT state, with milestones, safety and a rubric.
  4. 10.4 Capstone: An Open-Source Cell Monitor: Capstone project: an open-source ROS 2 cell monitor that reads robot state, packed Modbus handshake bits and a camera check from stand-in servers, keeps a maintenance log, and ends with a real pull request. No hardware needed.

04. Chapter quiz

Before you start a project, take the Chapter 10 quiz to check that you know what each project asks for. Each question links back to the project page that covers it.

05. Feedback

robOSStics is being tested with students. If you finish a capstone, or get stuck on one, please get in touch and mention which project and milestone.
