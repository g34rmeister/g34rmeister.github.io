Chapter 3: Programming Industrial Robots

Gerald Lê Draft

01. Overview

Industrial robots are programmed very differently from a hobby rover. Instead of writing every line of C++ yourself, you work through the tools each robot maker provides: a handheld teach pendant, a graphical interface, a simulator on a PC, and a vendor-specific programming language. This chapter walks through those tools, using two widely used platforms as examples: Universal Robots collaborative robots (PolyScope 5 and URScript) and ABB industrial robots (RobotStudio and RAPID).

02. What you will learn

  • Programming modes: the difference between online and offline programming, and when to use each.
  • Teach pendants: how PolyScope 5 lets operators program a cobot without writing code.
  • Simulation: how ABB RobotStudio lets engineers build and test programs on a virtual robot.
  • Languages: the basics of URScript and RAPID, with short examples.
  • The bigger picture: how programming changes across industrial, mobile, vision-guided and swarm robots.

03. Articles in this chapter

  1. 3.1 Online vs. Offline Programming: The two ways industrial robots are programmed: online with a teach pendant or by hand guiding, and offline in simulation software.
  2. 3.2 Teach Pendants and PolyScope 5: How Universal Robots' PolyScope 5 interface lets people program a collaborative robot on the teach pendant, mostly without writing code.
  3. 3.3 ABB RobotStudio: An overview of ABB RobotStudio, offline programming and simulation software for ABB robots, and why engineers use it.
  4. 3.4 Robot Languages: URScript and RAPID: An introduction to two industrial robot languages, Universal Robots' URScript and ABB's RAPID, with short examples and a comparison.
  5. 3.5 Examples of Robotics Programming: How robot programming changes across industrial arms, mobile robots, vision-guided picking, state-machine behavior, swarms and safety layers.
