Using This in a Class

Gerald Lê

robOSStics is free to read and can be used as it is in a class, a club or a study group. This page collects what a teacher or group lead needs from the course itself: the chapter order, how long each chapter takes, which chapter is optional, how the quizzes work and what the capstone projects ask for.

01. Chapters and time

The chapters are meant to be taken in order. Each lesson page shows an estimated time; the table adds them up per chapter. All ten chapters come to about 902 minutes (roughly 15 hours) of reading and exercises, or about 738 minutes (roughly 12 hours) without the optional Chapter 6. Labs and capstones take longer than their reading time.

02. The optional chapter

Chapter 6 (Electronics and Control Basics) is an extra chapter. It can be skipped by groups that only program robots, and added for groups that build hardware. Capstone 10.3 (speed-controlled wheel) builds on it, so skip that capstone if you skip Chapter 6.

03. Quizzes are self-checks

Every chapter has a short quiz on the quiz page. The quizzes are there for learners to check themselves, not to grade them. Progress and quiz results are saved only in the learner's own browser, so they are not visible to a teacher and are lost if the browser's site data is cleared. If you need grades, use the capstone rubrics or your own assessment.

04. Capstone projects

Chapter 10 has four capstones. Each one is a small project with milestones, a list of what to hand in, and a grading rubric, so it can be used as a course project or worked through alone.

  • 10.1 Simulated work cell: builds on Chapters 1, 2 and 5.
  • 10.2 ROS 2 pick-and-place with MoveIt 2: builds on Chapter 4.
  • 10.3 Speed-controlled wheel: builds on Chapter 6 and needs hardware.
  • 10.4 Open-source cell monitor: builds on Chapters 3, 4, 7, 8 and 9.

05. Corrections and changes

Every lesson has a "Suggest an edit on GitHub" link under its references. If you find an error while teaching, please report it there or through the contact page, with the lesson number and, if you can, a source. How This Course Was Made explains how the lessons were written and checked.
